# Additional module for the Water + Coop systems (v23): requirements checklist

This maps the requests of `ADDITIONAL_MODULE_FOR_WATER_COOP_SYSTEMS_v23.xlsx` (version 58) to the code that implements
them and the tests that exercised them. The workbook is the Consolidated Import template of version 56 (rows under the
member) with the user's notes; it has two sheets:

| Sheet | What it holds | Notes |
|---|---|---|
| Import | the columns of the template (member_no ... bill_balance, A1 to AC1), two members on six rows (member 100301 with two savings accounts, a loan and a one-time bill balance on the rows under it; member 100302 with one savings account), and a column the user added: **AD1 "Cut-Off Date"** | AE11, with an arrow up to AD1; Q14 and Q15, with an arrow up from column P (savings_balance) |
| Columns | the Columns sheet of the Excel template: every column with its part, what it holds and whether it is needed (savings_cut_off_date and loan_cut_off_date among them) | none |

Status: **Done** means built, reachable from the menu, and run in the tests and in a browser on the sample database.

Version 58 has no migration (no table, column or page is added); see `UPGRADE_v58.txt`.

## 2. Decisions

| # | Decision | Reason |
|---|---|---|
| D1 | The cut-off date on the member's row dates all the member's lines without a date of their own, the rows under the member included; on a row under the member it dates only that row. | In the workbook the member's rows are one block: the date given once on the member's row is the date of the member's balances, and a row that needs another date (a loan's totals paid as of another day) says so on its own row. |
| D2 | A line's own date column keeps coming first, the page's cut-off date last. | The columns savings_cut_off_date, loan_cut_off_date and bill_date of version 56 mean what they meant; a file without any date is read as before. |
| D3 | The time deposits are saved with the logic of Import Time Deposit, not a new one. | The same checks, the same certificate numbers, the same entries and the same accruals as the time deposits imported on the Time Deposit Center. |
| D4 | A blank term or maturity date is worked out from the other. | The workbook names both; a former system often gives only one, and the two must agree. |
