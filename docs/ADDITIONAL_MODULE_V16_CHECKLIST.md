## 2. Decisions

| # | Decision | Reason |
|---|---|---|
| D1 | Regular - Joint is a member type of the joint kind (not a new kind). | The request asks for the same form as Associate - Joint; the kind decides the form, the type decides regular or associate. |
| D2 | The address sub-groups stay one list, the one of Member Types, Clusters & Other Lists, managed from three places. | The member and the water-service account choose from the same list; two lists would drift apart. |
| D3 | An unposted reading is deleted, not marked deleted. | One reading per account and period is allowed; the deletion and its reason, with the reading as it was, are kept in the water audit log. |
| D4 | A reading followed by a reading of a later period is not deleted. | The later reading's previous reading was taken from it. |
| D5 | Incremental searching was given to the shared list box and to the shared searches, so every Water Billing page has it. | One behaviour on every page; the pages that search the server keep doing it, from one letter. |
| D9 | Enter in a member search takes a result only once the list shows the answer to the letters typed; a late answer to an earlier query is dropped. Tab takes a match only when one is left. | A quick typist never gets an account of an older, broader search; leaving a box never changes it by surprise. |
| D6 | The time deposit correction is in the reports only. | The CAIW entries were right; the subsidiary ledger left out what was withdrawn. |
| D7 | The pre-printed layouts are kept with the company settings, as JSON, with no new table. | No migration of the schema is needed for them, and they follow the company in a multi-company installation. |
| D8 | The choice of Printed or Pre-Printed can be overridden once on each receipt (a link). | A form can run out; the receipt still prints on plain paper. |
